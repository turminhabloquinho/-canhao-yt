Política de Privacidade do app Bloquinho

Última atualização: 29 de outubro de 2026.

O app "Bloquinho" é usado exclusivamente pelo dono do canal Turminha do Bloquinho para publicar e organizar vídeos no próprio canal do YouTube, por meio da API de Dados do YouTube.

Dados acessados

O app acessa somente a conta do YouTube do próprio dono, com a permissão que ele concede, para enviar vídeos, definir miniaturas, criar playlists e atualizar as informações do canal.

Uso e compartilhamento

Os dados não são vendidos, compartilhados com terceiros nem usados para publicidade. O token de acesso fica armazenado de forma privada e pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Crianças

O canal publica conteúdo para crianças, mas o app não coleta nenhum dado de espectadores, crianças ou outros usuários.

Uso de dados das APIs do Google

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado, e os Termos de Serviço do YouTube.
